# Help-student
## Запуск

На Windows можно запустить сайт двойным кликом по файлу:

```bat
start_site.bat
```

Он откроет сайт в браузере по адресу `http://127.0.0.1:8000`.

Также можно запустить вручную:

```bash
python server.py
```

После запуска сайт будет доступен по адресу `http://127.0.0.1:8000`.

Админ-панель: `http://127.0.0.1:8000/admin`

## Данные и резервные копии

Пользователи, чаты, заявки, отзывы и работы хранятся в SQLite. На Amvera база и загруженные файлы размещаются в постоянном каталоге `/data`; локальный запуск использует каталоги `data` и `uploads` проекта. При первом запуске старые JSON-файлы и база из каталога проекта переносятся в постоянное хранилище.

Войдите в админ-панель и нажмите **«Скачать базу данных»**, чтобы получить согласованную резервную копию SQLite. Файл можно открыть SQLite-просмотрщиком. Доступ к скачиванию требует учётные данные администратора.

Для размещения задайте `ADMIN_USERNAME` и надёжный `ADMIN_PASSWORD` в переменных окружения хостинга.
